# bin/

This directory holds the `fpcalc` Chromaprint binary. It's **gitignored**
because it's platform-specific.

## Get fpcalc

Download the latest release from
https://github.com/acoustid/chromaprint/releases (the `chromaprint-fpcalc-*`
asset for your platform), unzip, and drop `fpcalc` (or `fpcalc.exe` on
Windows) here.

Tested with v1.6.0.
